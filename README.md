# Mozakra – UI/UX Design

## About the Project

Mozakra is an educational platform designed to help students access their study materials, read and download books, take notes, and interact with an AI chatbot in one place.

## My Role

UI/UX Designer

## Tools

* Figma
* FigJam

## Key Features

* Modern and user-friendly interface
* Course materials
* Books and study resources
* Notes section
* AI Chat
* Student-friendly navigation
